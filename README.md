# Gaming Time Analyzer

A small Python console program created to help gamers keep track of watch and study their screen time across games.

-----

## Overview

much gaming that is not watched can affect work, health and daily life. The Gaming Time Analyzer offers a command-line interface to record gaming sessions track total activity and average hours spent find out which games are played the most check against daily gaming limits and create detailed summary reports.

-----

## Features

- **Session Logging:** Keep track of the date of the session the game title and the hours played with checks to make sure hours are not negative.

- **Session History:** See a list of all recorded sessions in order.

- **Time Analysis:** Figures out hours played and average time per session automatically.

- **Game Breakdown:** Add the time spent on each game. Finds out which game is played the most.

- **Limit Checker:** Checks session lengths against a limit set by the user. Gives a warning when limits are gone past.

- **Comprehensive Report Generation:** Gives a summary of the number of sessions, stats and all individual records, in a neat report format.

-----

## Technologies / Tools Used

- **Language:** Python 3.x

- **Libraries / Modules:** Standard Python built-in libraries (no outside third-party dependencies needed)

- **Interface:** Command-Line Interface
