# Project Statement-Gaming Time Analyzer

#1. Problem Statement

Video games are more popular than ever. Many people spend their time on playing games without realizing how time they are using. This can create problems like poor time management feeling tired and missing things like school, work or other responsibilities.

Most players don’t have a way to track their gaming habits. They can’t easily record playtime see patterns or check if they are going over their limits. There is a need for a distraction- way to monitor gaming time.


# 2. Scope of Project

## In Scope:

- A command line interface, where users can enter gaming sessions with date, game, name and time played .

- Data stored in memory can be viewed as a list of sessions.

- Input checks to avoid entries, such as negative hours or impossible values.

- Analysis tools to calculate time spent average session length, how time is split across games and which games are played the most.

- A way to set a custom limit per session and get alerts when a session goes over that limit.

- Report that appear directly in the console with summaries.

## Out of Scope:

- Saving data to files like JSON , CSV or SQLite.

- A interface or web based version of the tool.

- Automatic tracking of games, that are running in the background.

- Syncing of data across devices.


# 3.Target Users

- **Competitive Gamers:** People, who want to stay in the control of their playtime.

- **Students:** Learners who want to create balance study and fun by setting goals.

- **Parents/Guardians:** Caregivers who want to see how time their children spend playing games.


# 4.High-Level Features
-**Session Management Module:** User can add gaming sessions, see a list of past sessions in an easy to read format.

- **Time & Trend Analytics Engine:** Calculates gaming hours, session time and shows trends over time.

- **Title Distribution Analyzer:** Tracks time spent on each game. Points out the played one.

- **Threshold Limit Checker:** Users can set an allowed time per session. Any session that goes over is flagged.

- **Summary Reporting:** Gives an overview of all activity including time average play and past sessions, for quick review.
